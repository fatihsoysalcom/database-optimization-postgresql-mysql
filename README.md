# Database Optimization PostgreSQL MySQL

This Python script simulates basic database operations for PostgreSQL and MySQL, demonstrating the impact of indexing on query performance. It includes functions for creating tables, inserting data, adding indexes, and executing queries, highlighting how optimized configurations can speed up data retrieval, especially for AI workloads.

## Language

`python`

## How to Run

Run this Python script using: python db_optimizer.py
